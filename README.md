# DINO-CUPONES

Aplicación web romántica tipo PWA construida con HTML, CSS, JavaScript, Three.js y Firebase.

## Flujo
1. Dinosaurio 3D corre y entrega una carta.
2. Carta de bienvenida.
3. Inicio de sesión.
4. Cupones activos, por completar, canjeados y vencidos.
5. DinoMural para fotos y videos.
6. Panel administrativo para cupones, mensajes, usuarios y descargas.
7. Firebase Authentication, Firestore, Storage y Cloud Messaging.

## Estado actual
El sitio funciona en modo demo mientras `js/firebase-config.js` conserve los valores `TU_...`. Esto permite revisar toda la experiencia visual antes de conectar la base de datos real.

## GitHub Pages
El repositorio incluye `.github/workflows/pages.yml` para desplegar automáticamente cada actualización de `main`.
